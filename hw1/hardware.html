Network Hardware

Routers

Routers connect different networks and direct data between them. They examine destination IP addresses to determine where information should be sent. A common example is a home router that connects a local network to the internet.

Switches

Switches connect devices within the same local network. They use MAC addresses to forward data to the correct device, allowing computers and other equipment to communicate efficiently.

Wireless Access Points

Wireless access points allow Wi-Fi devices to connect to a wired network. They are commonly used in homes, schools, and businesses to provide wireless connectivity.

Network Interface Cards

A network interface card (NIC) provides the connection between a device and a network. Depending on the hardware, it can support wired Ethernet or wireless communication.
